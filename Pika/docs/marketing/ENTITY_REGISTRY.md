## Detailed Conflict Analysis & Recommended Alignments

### 1. `/cozumler/personalization` vs `/cozumler/journey-manager`
- **Conflict:** The route `/cozumler/personalization` rendered a view titled *"Müşteri Etkileşim Yönetimi / Journey Orchestration"* that discussed event triggers, delays, and journey flows. Meanwhile, `/cozumler/journey-manager` is the canonical full page for customer journey automation.
- **Root Cause:** Early architecture used `/cozumler/personalization` as a generic placeholder before the formal `JourneyManager` product module was built.
- **Resolution (P01):** Resolved in P01 via permanent 301 redirect from `/cozumler/personalization` to `/cozumler/journey-manager` (and `/en/solutions/personalization` to `/en/solutions/journey-manager`).

### 2. `/cozumler/template-management` vs `/cozumler/content-studio`
- **Conflict:** Early architecture had an initial stub route `/cozumler/template-management` that was misnamed and superseded by canonical template design tooling.
- **Root Cause:** Route was misnamed during initial stub creation.
- **Resolution (P01):** Resolved in P01 via permanent 301 redirect from `/cozumler/template-management` to `/cozumler/content-studio` (and `/en/solutions/template-management` to `/en/solutions/content-studio`). For audience segmentation, the canonical entity is **Audience Manager** (`/cozumler/audience-manager`).

### 3. `/cozumler/ab-testing` vs `/cozumler/campaign-manager`
- **Conflict:** The route `/cozumler/ab-testing` rendered a view titled *"Kampanya Otomasyonu ve Zamanlama / Campaign Automation & Scheduling"*, which duplicated core Campaign Manager features.
- **Root Cause:** A/B testing was stubbed as an independent solution page rather than being presented as a feature capability within Campaign Manager.
- **Resolution (P01):** Resolved in P01 via permanent 301 redirect from `/cozumler/ab-testing` to `/cozumler/campaign-manager` (and `/en/solutions/ab-testing` to `/en/solutions/campaign-manager`).

### 4. "Müşteri Etkileşim Yönetimi" vs "Journey Orchestration / Journey Manager"
- **Conflict:** Older views and meta descriptions used the phrase *"Müşteri Etkileşim Yönetimi"*. Modern product canon uses *"Müşteri Yolculuğu Otomasyonu"* (Journey Manager).
- **Recommended Alignment:** Adopt **Journey Manager / Müşteri Yolculuğu Otomasyonu** as canonical. Avoid "Müşteri Etkileşim Yönetimi" as it is easily confused with generic CRM helpdesk ticketing.

### 5. "BI" vs "Analytics & Reporting"
- **Conflict:** Wiki articles call the executive view *"BI Kokpit"*, while marketing views and routes use *"Analytics & Reporting"*.
- **Recommended Alignment:** Harmonize hierarchically: The solution/product domain is **Analytics & Reporting** (`/cozumler/analytics-reporting`). The specific executive dashboard tool within that domain is the **BI Kokpit**.

### 6. "Opportunity Engine" vs "Günün Fırsatları"
- **Conflict:** Some English pages refer to the engine as "Opportunity Engine", while Turkish marketing pages use "Günün Fırsatları" and English views use "Daily Opportunities".
- **Recommended Alignment:**  
  - *User-Facing Feature Name:* **Günün Fırsatları** (TR) / **Daily Opportunities** (EN).  
  - *Underlying Technology Description:* **Fırsat ve Karar Motoru** (TR) / **Opportunity & Decision Engine** (EN).

### 7. "Customer 360" vs "Pika 360"
- **Conflict:** Some copy refers to "Customer 360", while the platform brand is "Pika 360".
- **Recommended Alignment:** Standardize on **Pika 360**. Use "360° müşteri profili" only as an explanatory descriptive phrase, never as the primary entity name.
